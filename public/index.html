ⓘ If your user accounts were lost (e.g. due to a Firebase quota incident), this tool reads all unique engineer names and user IDs from your existing entries and lets you restore them with one click. Section Incharges are detected from the si field on entries.
Migrate Legacy %-Mode Entries → Quantity
ⓘ Old entries were submitted in %-mode (only todayPct stored). The app already back-fills qtyToday in memory when loading them, but Firestore documents still don't have the field. This tool computes qtyToday = qty × todayPct / 100 using each entry's snapshot master quantity at submit time, and writes it to Firestore so the data is consistent. Safe to re-run — only entries missing qtyToday are updated.
